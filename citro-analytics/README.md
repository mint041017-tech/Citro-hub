# Citro 增长分析 · 本地演示工作台

面向 Citro APP 与网页业务数据查看的响应式分析工作台。当前版本只使用本地虚构演示数据，不含登录、支付、数据库或外部服务连接。

## 运行

无需安装依赖。任选一种静态服务器：

```bash
# Node.js
npx serve dist

# 或 Python 3
python -m http.server 4173 --directory dist
```

打开终端输出的本地地址即可（Python 方式为 <http://127.0.0.1:4173/>）。

## 目录

```text
citro-analytics/
├─ site/                 # 源文件
│  ├─ index.html
│  ├─ styles.css
│  ├─ app.js
│  ├─ data.js            # 全部演示数据集中在这里
│  └─ favicon.svg
├─ dist/                 # 可直接运行的静态构建产物
├─ build.mjs             # 将 site/ 同步到 dist/
└─ README.md
```

修改源文件后执行：

```bash
node build.mjs
```

## 已实现

- 时间范围（近 7 / 30 / 90 天）同步更新四项指标、收入趋势面积图、套餐收入环图与数据表。
- 桌面左侧导航与顶部工作区位置、任务/通知搜索；手机端折叠为抽屉导航。
- 搜索同时筛选任务与通知，并显示匹配数量和空状态。
- 任务勾选后立即更新完成数与进度条。
- 单条通知和“全部标为已读”操作，未读数量同步到导航。
- 导出当前时间范围的 CSV，包含指标、收入序列与套餐 MRR 分摊。
- 数据说明弹窗、跳过导航链接、可见焦点、语义化表格和键盘可操作控件。
- 页面可纵向滚动，无固定画布尺寸；手机端指标卡和图表单列排布。

## 演示数据说明

- `data.js` 中所有人物、客户、收入、任务、通知与业务变化均为虚构样例，页面内有持续可见的“本地演示”标识和数据说明。
- 时间范围切换、搜索、任务状态与通知状态只保存在当前页面内存中，刷新后恢复初始演示状态。
- CSV 文件名和内容都标注为演示数据。

## 后续接入真实 APP / 网页数据

视图与数据层已经分离：`data.js` 提供页面所需的数据结构，`app.js` 负责渲染与交互。接入真实数据时，可以用后端返回的数据替换 `window.CITRO_DEMO` 中的 `ranges`、`tasks`、`team` 与 `notifications`，并保持字段一致。

真实数据接入需要在服务端处理身份验证与访问权限，不应把数据库凭据或高权限接口密钥放进浏览器。当前版本未实现这些集成。
