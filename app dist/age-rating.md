# 年龄分级问卷草稿

> App Store Connect 的年龄分级问卷会随政策更新；以下按 Citro 实际内容给出建议答案，最终以后台当前问题为准。
> 不要把年龄分级当成“越低调越好”；UGC、AI 与第三方网页访问如果漏报，审核会直接质疑。

## 内容判断

| 问卷主题 | 建议答案 | 依据 |
| --- | --- | --- |
| 卡通/幻想暴力 | 无 / None | 小游戏是休闲玩法；极限刹车没有血腥或写实伤害 |
| 写实暴力 | 无 / None | 无写实暴力画面 |
| 长时间极端暴力 | 无 / None | 无 |
| 脏话/粗俗幽默 | 视 UGC 实际情况，至少“偶尔/轻微” | 社区用户可能发布；有举报、拉黑、运营者处理 |
| 酒精、烟草、毒品 | 内置内容无 | 社区 UGC 需审核；如出现按实际申报 |
| 成人/暗示性主题 | 内置内容无 | 社区 UGC 需审核；如出现按实际申报 |
| 恐怖/惊悚 | 无 | 无恐怖游戏内容 |
| 医疗/治疗信息 | 无 | AI/星象/抽签均标注仅供娱乐，不构成专业建议 |
| 赌博 | 无 | 抽签、抽卡、排行榜都是免费娱乐，不涉及真实货币、充值、兑换现金或博彩 |
| 竞赛 | 无 | 排行榜是休闲成绩展示，无付费赛事 |
| 无限制网页访问 | 建议先填“无”，但需收紧 | App 内 WebView 打开固定的第三方资源页，没有地址栏；如果用户可在页面内任意跳转，审核可能视为“无限制网页访问” |
| 用户生成内容（UGC） | 有 | 社区图文/语音/评论/匿名发帖；有举报、拉黑、运营者审核 |
| AI 生成内容 | 有 | CiCi 对话、星象、好事回复；标注仅供娱乐，可举报 |

## 预期评分

- 不能直接承诺最终等级；Apple 会根据问卷和内容计算。
- 以当前内容，可能是 **12+/13+**；如果 UGC 审核能力不足、出现成人内容或可任意浏览网页，可能被要求 **17+** 或直接拒审。
- 如果拿到较低年龄分级，但社区允许匿名成人内容，审核仍可能按 Guideline 1.2 处理；分级低不等于免责。

## 提交前收紧动作

1. **网页访问**：给 `InAppWebPage` 加域名白名单，只允许 `chimu-claw.xyz`、`obs.chimu-claw.xyz` 等固定域名；或把外部链接改为系统 Safari 打开，避免“无限制网页访问”。
2. **社区内容**：确保举报入口在每条动态和评论上；拉黑可用；运营者能及时处理举报。
3. **AI 内容**：保留“仅供娱乐”提示；对违法/色情/暴力请求有拒绝策略；用户可举报 AI 回复。
4. **抽签/抽卡**：不要加入付费抽卡、现金兑换、概率公示缺失等博彩特征；当前免费娱乐定位保持不变。
5. **截图与文案**：不要展示成人、暴力、赌博或真实用户隐私内容。

## 中国区额外注意

年龄分级不等于中国的未成年人保护合规。中国区还需考虑实名、未成年人模式、内容审核、生成式 AI 备案等，见 `china-compliance.md`。
