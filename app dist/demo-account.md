# 审核演示账号准备

> 目标：审核员拿到账号后，5 分钟内能看到 Citro 的主要功能，不需要邀请码、不需要真实用户数据。

## 1. 创建专用账号

- 使用专用测试手机号，不要用个人主账号。
- 昵称建议 `AppReview` 或 `CitroReview`，头像用中性默认图。
- 生日/星座可填可不填；如果填，不要使用真实个人信息。
- 密码使用独立强密码，保存在密码管理器；**只填进 App Store Connect，不写进仓库**。
- 账号不要设为管理员；只要普通用户权限，能完整体验即可。

## 2. 准备可审核的数据

审核员打开社区时不应看到空页面或 QA 垃圾。用演示账号准备：

- [ ] 2–3 条社区动态：文字 + 图片，内容为产品介绍/日常，避免真实用户隐私
- [ ] 1 条语音动态（测试麦克风与播放）
- [ ] 1 条评论、1 个点赞/抱一抱
- [ ] 1 份食谱（含步骤图）
- [ ] 1 条笔记、1 个冰箱/购物清单条目
- [ ] 1 个游戏成绩/排行榜记录
- [ ] 1 次抽签/卡面收藏记录（验证卡面同步）
- [ ] 1 条与 CiCi 的 AI 对话（验证 AI 回复）
- [ ] 确认“我的 → 黑名单”可用；如为空，准备一个测试昵称用于拉黑演示（可选）

> 演示数据应像真实产品内容，但不要使用真实用户手机号、微信、地址或私密照片。

## 3. 验证清单

- [ ] iPhone 上登录成功，首页、社区、游戏、食谱、我的都能打开
- [ ] iPad 上登录成功，横屏/竖屏/分屏布局正常
- [ ] AI 能返回回复；图片分析可用（如果该功能在 1.9.9 开放）
- [ ] 社区举报入口可见；举报后不报 404
- [ ] 黑名单可添加/解除
- [ ] 账号注销入口可见；用一次性账号测试，不注销演示账号
- [ ] 通知权限、定位、相机、麦克风、相册权限文案正常
- [ ] 退出登录后游客状态仍可浏览首页

## 4. 审核期间维护

- 演示账号保持可登录，不要改密码、不要注销、不要改昵称。
- 后端保持在线；如果必须维护，避开审核时段，并在审核备注里留备用联系方式。
- 如需测试注销，另建 `DeleteTest` 账号，测试后不影响演示账号。
- 审核通过后再决定是否删除演示账号；建议保留一段时间，便于后续版本审核。

## 5. 安全

- 不要在 `review-notes.md`、`metadata.md`、截图或提交信息里写真实密码。
- 不要把账号密码发给无关人员；App Store Connect 的 App Review Information 是唯一填写位置。
- 如果密码泄露，立即改密码并同步更新 App Store Connect。
