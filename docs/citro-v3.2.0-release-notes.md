# Citro 3.2.0 发版记录

> 版本号：`3.2.0+3200` · 2026-11-17
> 汇总区间：3.1.68 → 3.2.0

## 游戏页（手机竖屏）

- 手机竖屏（宽 ≤ 600 且竖放）的所有 `GameScaffold` 游戏共用新顶栏：游戏名靠左，
  错误 / 用时 / 最佳等只读读数缩小收进顶栏右侧；顶栏不再显示 logo、头像与账号入口。
- 读数按真实文本宽度排布：标题过长、系统大字号或多位数分数放不下时，
  自动折到标题下方一行，不挤占游戏名。
- 读数卡收起后棋盘整体上移，难度条与棋盘之间留出 24dp 间距；
  淘气小球与跳一跳显式提供顶栏读数。
- 平板、桌面与横屏保持原来的「居中标题 + 棋盘上方读数卡」版式，棋盘逻辑不变。

## 微信小程序（0.2.4，独立上传）

- 小程序与 App 共用同一套账号和 `trashapi` 后端，最终收敛为
  「首页 / 计划 / 玩法 / 我的」四个 tab、13 个页面。
- 计划数据离线优先并按整包 LWW 对账；玩法抽签改为云端发签 + 16 帧动画，
  支持全站记录、10 秒静默轮询、下拉刷新与原生分享。
- 首页改用纯 CSS 时段渐变，移除打卡、卡面与天气页面，代码包减少约 639KB。

## Android 端

- 手机竖屏游戏页启用新的紧凑顶栏，长标题和多位数读数的折行兜底一并生效。
- 仅发 arm64-v8a 包，Impeller 保持开启，Citro 签名与旧版一致，可直接覆盖升级。
- 应用内更新清单 `APK/update.json` 同步到 3.2.0。

## iPad / iOS

- iPhone 竖屏游戏页启用新的紧凑顶栏；iPad 与横屏保持原版式。
- iOS 预打包完成：版本号与构建配置已同步到 3.2.0；
  推送 main 后由 TestFlight CI 在 macOS 上签名构建并上传。

## Windows 端

- 本版桌面端无界面改动：游戏页仍是居中标题与棋盘上方读数卡，功能与 3.1.68 一致。
- 修复「一起看」发起屏幕共享后系统音量被压低：WebRTC 在 Windows 上的音频
  播放流会被系统登记成通信流，触发 communications ducking，把其它应用音量
  降到 20%。现在 Windows 端声网在发布系统声时，Cloudflare 链路只发画面，
  系统声统一由声网送给新版客户端；网页端观众暂时听不到 Windows 主持人的
  共享声音（手机主持人不受影响）。
- 桌面端随 3.2.0 重新打包，安装包更新清单带 SHA-256 校验，静默更新与便携版同时可用。

## Web 端

- Flutter Web 与桌面端同源更新；浏览器窗口收窄到手机宽度并竖放时，
  游戏页启用紧凑顶栏，桌面宽度下保持原版式。
- 构建产物预压缩、CanvasKit 本地分发照旧，`latest.json` 同步到 3.2.0。
- downloads 静态站补上 3.2.0 三端更新日志，Android 与 Windows 入口更新到 3.2.0。

## 下载

- Android APK：`Citro-v3.2.0-release.apk`（arm64-v8a，Citro 签名，应用内更新可用）
- Windows 安装包：`Citro-v3.2.0-win64-setup.exe`（用户级安装，无需管理员，静默更新）
- Web 压缩包：`Citro-web-3.2.0.zip`（部署到站点根，清单 latest.json 已同步）
- downloads 站：`Citro-downloads-3.2.0.zip`（清单 downloads.json 已同步）
- iOS：预打包完成，IPA 由 TestFlight CI 生成，渠道不变
- 微信小程序：源码在 `miniprogram/`，版本 0.2.4，由微信开发者工具上传，不含独立安装包
