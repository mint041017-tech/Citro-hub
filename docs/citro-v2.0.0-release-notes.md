# Citro 2.0.0

> 版本号 `2.0.0+2000` · 2026-11-02

## 本次更新

### CiCi
- 新增「自定义性格」：温柔 / 元气 / 理性 / 毒舌 / 文艺预设，或自由输入专属设定，保存后立即生效。
- 性格与 App 知识分离：自定义性格会完整替换默认人设，名字始终固定为 CiCi。
- CiCi 已完整了解首页、听隅、食谱日记、游戏工具、社区、资源库、我的与 CiCi 自身功能。

### 转运与社区
- 跟 CiCi 分享的转运好事不再写入笔记，改为以「今日好事：…」同步为社区动态，图片一并发布。
- 发布结果会在对话中回显，失败不影响转运机会到账。

### 界面与交互
- 内嵌网页顶栏：刷新改为圆形按钮并紧邻返回，网站名称与网址居中显示。
- 首页星象卡、日历卡支持更多尺寸（迷你到整宽），并针对迷你档优化排版。
- 我的页新增「减弱动态效果」开关，开启后全局关闭页面滑动、缩放与呼吸动画。
- 统一全屏页面顶部留白：桌面 48，手机等窄屏 24。

### 稳定性与流畅度
- 入场动效改为不重建卡片子树，首页卡片独立图层，听隅切页只合成不重绘。
- 修复数独在手机端使用系统返回时直接退出，改为回到模式选择。
