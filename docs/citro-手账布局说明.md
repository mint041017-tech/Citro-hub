# Citro 手账拼贴首页（桌面实验版）

> 2026-10-19 · 布局方向：手账拼贴（Scrapbook / Journal Spread）
> 实现文件：`styles/citro-scrapbook.css`（加载在 `citro-refine.css` 之后）
> 一句话：把首页从「四栏等权卡片」做成一页摊开的手账 —— 左页封面，右页拼贴。

---

## 1. 设计概念

**一页摊在桌上的纸，而不是一块仪表盘。** 所有模块不再是「浮起的卡片」，而是纸面上的：
拍立得照片、贴纸票根、手写标签、索引卡。分区靠**纸张、装订边线、胶带和留白**，
不再靠一层层卡片边框。

- **圆角手账**：页面纸 16px、大海报 18px、拍立得/Mod/游戏卡 10–14px、搜索便签 14px、
  一言纸条 12px；圆角让拼贴从「剪报」变成「纸片贴纸」，更软。
- **顶部不再有固定顶栏**：账号 + 打卡 + 主题 + 首页/资源 收成一排 **胶囊**；
  下面是五块 **大小不一的手机小组件**：
  - 时间（2 列 × 1 行）：日期、星期、时钟；
  - 天气（4 列 × 2 行）：当前温度/体感/湿度/风速/风向 + 4 日预报，复用社区页天气卡；
  - 日历（3 列 × 2 行）：整月日历，今天高亮，复用社区页日历卡；
  - 摸鱼（2 列 × 1 行）：休息状态、日期、倒计时、距下班/休息日；
  - 星象（3 列 × 2 行）：每日运势 / 本命星盘 / 行运星盘入口。
- **封面页（左 1/3）**：logo 拍立得（150px 白边 + 纸胶带）、手写 Citro、状态与描述、
  三个统计印章；顶部「C」邮戳、底部淡 logo 水印。
- **首页右 2/3**：**12 个小游戏一次性全部展开**（4 × 3，无横向滚动、无「查看更多」）。
- **首页底部**：搜索便签 + 两张小入口卡（社区 / 食谱，已缩小成小纸片）+ 每日一言。
- **二级页「资源」**：游戏 Mod 和小工具/外设左右分栏：
  - 左：Mod 卡片改成 2 列网格，**6 张全部展示、不再横向滚动**；
  - 右：小工具（3 列）在上、外设驱动（3 列）在下；底部保留搜索便签。
  - 顶栏胶囊保留「首页 / 资源」切换；手机端沿用原有「资源」Tab 的资源页。
- **页面细节**：奶油纸 + 纸纤维噪点 + 33% 装订边线；深色模式是「夜里的手账」
  （近黑纸、暖白墨、贴纸低饱和）。
- **不整齐是故意的**：模块给 -0.45°～+0.45° 微旋转和 1–8px 位移，分区标题各自倾斜
  （-0.8°～+0.5°）；但正文保持水平，避免阅读时头晕。
  ⚠️ 唯一例外：**搜索卡不能加 transform** —— 它的浮层是 `position:fixed`，父级一旦有
  transform，浮层会以卡片为参照定位（实测会跑到视口外）。搜索的手账感由纸纹、虚线边、
  胶带和手写字体承担，卡片本身保持水平。

## 2. 布局栅格（桌面）

```
┌──────────────────────────────────────────────────────────────┐
│ 胶囊：账号+打卡 · 主题 · 首页/资源                              │
├──────────┬───────────────────┬──────────┬────────────────────┤
│ 时间     │ 天气（4 列 × 2 行）│ 星象     │ 日历（3 列 × 2 行）  │
├──────────┤                   │          │                    │
│ 摸鱼     │                   │          │                    │
├──────────┴───────────────────┴──────────┴────────────────────┤
│  封面 / Hero（左 4 列）      │  小游戏 12 个全部展开（右 8 列）  │
│                              │                                │
├──────────────────────────────┴────────────────────────────────┤
│ 搜索便签 │ 社区小卡 │ 食谱小卡 │ 每日一言（小纸条）              │
└──────────────────────────────────────────────────────────────┘

资源页（#/res）：
┌──────────────────────────────────────────────────────────────┐
│ 胶囊：账号+打卡 · 主题 · 首页/资源                              │
├──────────────────────────┬───────────────────────────────────┤
│ 游戏 Mod（2 列 × 3 行，   │ 小工具（3 列）                     │
│ 6 张全部显示，不滚动）     │                                   │
│                          ├───────────────────────────────────┤
│                          │ 外设驱动（3 列）                   │
├──────────────────────────┴───────────────────────────────────┤
│                   ｜   手账搜索便签（整行）                      │
└──────────────────────────────────────────────────────────────┘
```

实现：`main-root` 栅格为 `auto repeat(8,1fr)`（首页）与 `auto repeat(7,1fr)`（资源页）。
- 首页：胶囊第 1 行；小组件第 2–3 行；封面与小游戏第 4–8 行；底部小卡第 9 行。
- 资源页：胶囊第 1 行；Mod 左 1–6 列、工具/外设右 7–12 列；搜索占第 8 行。
- 小组件尺寸不同（1 行 / 2 行高、2/3/4 列宽），不再是一排等大卡片。
- 小工具 / 外设驱动 / Mod 在首页 `display:none`；资源页才出现，顶栏胶囊负责切换。
- 整体再各自做 1–8px 位移和微旋转，所以看起来不齐但仍有结构。

## 2.1 小组件数据来源

天气和日历组件不重新请求接口，而是**复用社区页（#/trash）已经渲染好的天气卡、日历卡**：
`index.html` 末尾新增一段小脚本，等 `#tkWxBody` / `#tkCalGrid` 渲染完成后克隆进
`#homeWxBody` / `#homeCalGrid`；摸鱼组件同样在页面加载后点开一次摸鱼弹层，把状态/倒计时
复制进卡片后再收起。这样不用重复写天气/日历逻辑，也不会增加接口请求。

## 3. 生效范围与回退

- **生效**：`(min-width:1025px) and (min-height:880px)` 的桌面窗口。
- **短窗口**（< 880px 高）：自动回落到上一版「精致 Bento」，避免照片带被压扁。
- **手机 / 平板**（≤1024px）：这一轮不动，仍是现有 app-shell + 底部 Tab 布局。
- **回退**：删掉 `index.html` 里这一行即可，其余文件不受影响：
  ```html
  <link rel="stylesheet" href="styles/citro-scrapbook.css">
  ```
  （`citro-refine.css` 那套「精致 Bento」会原样回来。）
- 不涉及 HTML 结构的破坏性改动：模块 id / class / JS 绑定保持原样；新增的只有首页天气/日历
  小组件容器和一段克隆数据的脚本（Mod 轮播、工具渲染、社区计数、搜索浮层、主题切换都按原逻辑工作）。

## 4.1 第二轮反馈修订（2026-10-19 04:10）

用户反馈：封面留白浪费空间、搜索框不够手账、整体排列可以更随意。对应改动：

- **封面压短 + 填满**：封面从 7 行缩到 6 行（818→718px），logo 186→204px、标题 62→84px、
  统计 40→46px；封面下方空出的位置放进两张小票根（社区/食谱），底部用淡 logo 水印 +
  左上「C」邮戳填住，避免大面积空白。
- **搜索改手账便签**：奶油纸底 + 每 30px 一条横线 + 虚线边框 + 顶部胶带 + KuaiLe 手写
  placeholder + 图标微倾斜；聚焦时纸条稍微「亮起来」。
- **排列更随意**：模块加 -0.45°～+0.45° 微旋转和 1–8px 位移；三个分区标题各自倾斜；
  票根一上一下错开；工具列整体下移 7px、左移 7px 与 Mod 轻微交叠，像贴上去的。
- **踩到的坑**：给搜索卡加 transform 后，`position:fixed` 的搜索浮层改以卡片为参照定位，
  打开时会跑到视口外（top≈1475px）。已把搜索卡恢复为无 transform，手账感交给纸纹/胶带/字体；
  浮层定位恢复正确（输入框 y≈940，浮层 y≈540）。

## 4.2 第三轮反馈修订（2026-10-19 04:2x）

用户反馈：手账要「带一点圆角」、小工具与外设驱动收进二级菜单、不在首页直接显示。

- **圆角手账**：页面 16px、大海报 18px、拍立得/Mod/游戏卡 10–14px、搜索便签 14px、
  一言纸条 12px；去掉规则的折角/撕边，改用纸片圆角 + 胶带保留手账感。
- **工具 / 外设收进二级页**：首页不再渲染这两块；顶栏新增 `首页 / 资源` 导航（仅桌面手账布局
  显示，手机仍用底部「资源」Tab）；`#/res` 成为资源二级页：工具 2 列印章目录 + 外设 3 列索引，
  底部搜索便签；手机端沿用原有资源页（Mod + 工具 + 驱动），未改。
- **首页重构**：封面（6 行）+ 宽幅 Mod 照片带（5 行，4 张卡 + 一排小游戏）+ 两张社区/食谱

- 顶栏导航只在桌面手账布局出现：`html.app-shell .meta-nav{display:none}`，不影响手机。
- 已复测：首页 / 资源页在 1440×1000、1280×900 浅深色正常；无横向溢出；搜索浮层在首页与
  资源页都能正确定位（输入框 y≈849 / 934，浮层在其上方）；工具/外设在首页 `display:none`、
  资源页 `display:flex`；手机 390×844 首页与资源页维持原布局。

## 4.3 第四轮反馈修订（2026-10-19 04:5x）

用户反馈：小组件要像社区里的天气/日历卡那样显示详细信息、卡片不要等大且不要留白、
账号/打卡/浅深色改回胶囊、Mod 不滚动且与工具/外设左右排列、小游戏一次全展示。

- **小组件详情化**：时间卡显示日期/星期/时钟；天气卡复刻社区天气卡（当前/体感/湿度/风速/
  风向/4 日预报）；日历卡复刻社区日历（整月 + 今天高亮）；摸鱼卡显示休息状态/日期/倒计时/
  距下班/距休息日；星象卡显示每日运势/本命星盘/行运星盘入口。
- **尺寸不再统一**：时间/摸鱼为 1 行高、2 列宽；天气 2 行高 4 列宽；星象 2 行高 3 列宽；
  日历 2 行高 3 列宽；通过网格位置形成大小错落，卡片内容贴顶不拉伸。
- **账号/打卡/主题改回胶囊**：头像 + 打卡合为一枚胶囊；主题和「首页/资源」为独立胶囊。
- **小组件数据复用**：天气 / 日历直接从社区页已渲染的 `#tkWxBody` / `#tkCalGrid` 克隆；
  摸鱼在加载后点开一次弹层取状态再收起，不重复写接口逻辑。
- **小游戏全展示**：首页隐藏 Mod 带，只保留小游戏，12 个游戏 4 × 3 一次全部显示。
- **Mod 与工具/外设左右排列**：资源页左 1–6 列为 Mod（2 列 × 3 行网格，6 张全显示、
  不滚动），右侧小工具在上、外设驱动在下；底部搜索便签。
- **手机端修复**：星象按钮原先嵌在天气胶囊内，拆出后手机端会单独占一行；现改为手机隐藏、
  入口保留在天气弹层的「星象」tab 里。

## 5. 还可以继续打磨

1. **移动端手账化**：手机是独立的 app-shell 布局，可单独做「单页手账」：封面拍立得 + 状态 +
   竖向堆叠的贴纸票根；底部 Tab 不变。
2. **真实素材**：目前照片位复用了 Mod 封面 / 游戏缩略图；如果补一些真实照片（桌面、外设、
   手写便签），拼贴感会真正成立。
3. **手写批注 / 贴纸**：给「本周主推」「今天吃什么」这类位置加 1–2 条真实手写批注，
   但保持稀缺（每屏 1–2 个），否则会幼稚。
4. **轻交互**：照片悬停摆正（已有）、点击票根轻微「贴纸翘起」、拖动排序（成本较高）。
5. **布局切换**：如果之后想要「手账」和「Bento」并存，可在主题菜单加一项「布局」，用
   `html[data-layout]` 控制，不用改 HTML 结构。
6. **矮屏策略**：目前 < 880px 高回退 Bento；如果常用 1440×800 窗口，可以再做一版
   「紧凑手账」（照片带缩成横条、票根并排）。
