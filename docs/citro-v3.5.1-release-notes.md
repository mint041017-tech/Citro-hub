# Citro 3.5.1 发版记录

> 版本号：`3.5.1+3501` · 2026-11-28
> 汇总区间：3.2.1 → 3.5.1（累计更新）

## 3.5.1 本轮

- 天气详情、心情详情弹窗提高玻璃模糊强度并加深深色模式填充，正文与次级信息更清晰。
- 首页天气卡字号整体上调：标签、城市、天气描述、体感/湿度与更新时间同步放大，窄卡按原布局自适应不溢出。
- Android 动画针对优化：滚动与切 Tab 期间底栏玻璃临时降低实时模糊并补填充，静止后恢复完整模糊，减少移动背景每帧重采样造成的掉帧。

## 测试中心与十二系（3.3.5）

- 新增「测试」中心，聚合 16 型测试与十二系亲密关系测评。
- 十二系：40 题正反对称量表、5 个正交维度、12 个等半径原型；结果含五维雷达、原型占比、600 次蒙特卡洛稳定率、成人依恋平面与 Curran 效度审计。
- 结果页按原版结构三 Tab：画像与占比 / 五维与效度 / 关系动力学；宽窄屏均无溢出。
- MBTI 图鉴删除，历史结果改为「测试档案」内联回顾；档案随账号同步，同 id 按更新时间合并。
- 新增 `/api/kei` 与 `KeiStore`，旧记录缺审计字段时保持兼容。

## MBTI（3.3.0 → 3.3.5）

- 上线 96 题 MBTI 测试，入口只保留单套测试，不再展示快速版 / 标准版 / 完整版措辞。
- 结果页生成“专属人格切片”，增加行为倾向与关系提示；分享改为一键生成带测试二维码的 PNG 长图。
- 历史记录按账号同步，最多保留 30 条；登录、扫码登录、注册后拉取，退出时清理本机记录。
- 3.3.5 起图鉴入口移除，测试报告统一从「测试档案」打开，返回转场缩短。

## 每日打卡与每日一签（3.3.0 → 3.3.1）

- 每日打卡升级为“抽签 → 行动 → 回签 → 七日成卷”的记录链路。
- 手机抽签页重做：今日一签 + 日期/星期，标签收敛；今日签改为独立朱砂色文字印记。
- 每日一签改为完全随机：等级 0–7 与签位 0–5 独立抽取，取消同级签按日期轮换；同日同身份只抽一次，跨天重抽。
- 签文改为七段分段流式输出：签题、诗、读签、关键词、今日一小步、忌、便签逐段呈现。
- 今日一小步增加生成后校验与手边动作兜底，过滤依赖他人、外出、购买、预约与等待回复的任务。

## 社区（3.3.1）

- 客户端删除发帖 200 字上限，服务端取消 200 字截断并保留换行。
- 信息流按真实渲染宽度判断，超过五行折叠，可展开 / 收起；帖子与评论共用 `cleanText`。

## 登录注册与账号（3.3.x）

- 登录不再手选手机号 / 邮箱，输入后自动识别。
- 注册方式改为输入框内下拉切换，注册免昵称、增加确认密码，首次进入补全资料。
- 登录 / 注册切换加入胶囊动画；登录卡使用全局玻璃材质。
- 测试档案、卡面收藏、待办、记账与日历等记录随账号云端同步。

## 视觉、玻璃与游戏（3.3.5）

- 全局玻璃材质重新调校：浅色与深色统一通透度，深色边缘改为同色，底部标签栏加重模糊。
- 外部游戏卡片重新设计，游戏页封面下缘直角与整体圆角边界修正。
- 「我的」页深色玻璃、卡片颜色与背景铺满修复；测试 / MBTI / 十二系页背景不再露出白底。
- 测试、登录、游戏卡片与桌面/平板/手机布局统一按多比例自适应。

## Web 与性能（3.3.2）

- 浏览器横屏沿用 Windows 桌面版：208pt 侧栏 + 分栏首页，计划页并排卡片；竖屏宽窗口保持原布局。
- RoundedCN 去掉 500 字重，首屏 400/700 预加载；非首屏页面 deferred，首帧前下载量约降 31%。
- Web 产物移除未引用启动图与 mods，`main.dart.js` 从 6.04 MB 降至约 5.5 MB。

- 服务端需部署最新 `trash/trash.js` 并重启 PM2：十二系 `/api/kei`、MBTI 档案与卡面/打卡同步依赖该版本；未部署时客户端仅保留本地记录。

- `web/latest.json` 的 `build_id` 使用最终 `main.dart.js` 的 MD5，与 zip 内 `.last_build_id` 一致。
- 推送 `main` 后 `.github/workflows/ios-testflight.yml` 自动构建并上传 TestFlight。
