# Citro 视觉精修说明

> 2026-10-19 · Lead 视觉整理稿（配合 `styles/citro-refine.css` 阅读）
> 目标：在不推翻 Citrus Soda 身份（奶油纸 / 柑橘橙 / 手绘字标）的前提下，
> 让首页和内容页更像「一本有呼吸感的手账」，而不是「一层层贴纸盒子」。
> 用户口径：**橘色为主，薄荷只做少量点缀**；顶栏「今天也要开心」保留框。

---

## 0. 一句话设计判断

**Reading this as:** 个人向生活仪表盘（Crew 首页 + 食谱日记 + 社区 + 小游戏 + 工具聚合），
给站长自己和少数朋友使用，带着「柑橘汽水」的可爱语言；
这一轮不做换牌，做**克制化**：保留手写体与暖色，但把层级、字号、描边和强调色重新排布，
让「高级」来自秩序与留白，「温馨」来自纸面、暖影和手写体的稀缺使用。

---

## 1. 精修前诊断（改什么、为什么）

| # | 问题 | 具体表现 | 处理原则 |
| --- | --- | --- | --- |
| 1 | **层级平** | 111 个卡片元素、其中 42 个是卡中卡；外层卡 22px 圆角、内层 16px，都带 1px 白描边和暖投影，眼睛没有落点 | 三级表面：画布 → 卡片 → 内嵌；内嵌不再画边，只用一层「印上去的底色」 |

## 2. 已经落地的改动（`styles/citro-refine.css`，加载在 8 个页面皮肤之后）

### 2.1 纸面与层级
- 浅色画布 `#EFE8D8`、卡片 `rgba(248,242,229,.86)`、内嵌 `rgba(86,68,44,.05)`；
- 卡片只留 **1px 暖灰 hairline + 轻暖投影**，悬停才轻微抬升；
- Mod / 小游戏 / 工具 / 驱动条目全部去掉嵌套描边与独立阴影，改用同一层内嵌底色；
- 深色 `#0E0E10` + 抬升卡面 + 暖白描边，浮层阴影统一为黑色。

### 2.2 字体分工
- 界面标签（游戏 Mod / 小工具 / 外设驱动 / 小游戏）→ 13px 500、`.12em` 字距、橙色 5px 圆点；
- 条目名（Mod 名、游戏名、工具名、驱动名）→ 无衬线 500 / 12.5–13.5px；
- 正文说明 → 400 / 12px / 1.6；
- 保留手写体的位置：logo、Hero 标题、社区/食谱入口卡标题、Hero 统计数字、一言。

### 2.3 橙色纪律（用户 10-19 口径 · 已按最新要求收敛）
- 强调色整体改为**浅橘**：浅色 `--accent:#F7BC78`（填充）、`--accent-2:#E5A24C`、`--accent-lt:#FFDDAF`；深色 `#FFCB8E / #EBA75E / #FFE3BF`。
  浅底上的橙色**文字**仍用深橘 `--accent-ink:#94530A`（保证 AA 对比度，浅橘做文字会读不清）。
- 工具图标片、驱动圆点、小游戏卡底色、社区入口卡、展开链接、搜索聚焦、登录弹窗 tabs 选中 → 全部回到橙色系；
- 食谱页左侧导航选中态从大面积薄荷改为浅橘底 + 橙色左边条；
- 薄荷只保留：Mod 角标、宜/忌语义、状态徽章、游戏页内的小图标、极少量小面积光斑；
- 顶栏「今天也要开心」恢复为带 hairline 边框的胶囊，宽度收敛到 `min(32vw,340px)`，不再是一条长输入框。

### 2.3b 用户 10-19 二次口径（本轮已落地）
- **顶栏去掉 logo 与品牌名**：`.tile-meta .brand-chip{display:none}`，品牌只由 Hero 的 logo 承担。
- **底栏去掉 logo 与品牌名**：`.foot-brandline{display:none}`，每日一言居中占满底栏。
- **每日一言放大**：中文 17px / 英文 13.5px（手机 15px / 12.5px），颜色提到 `--ink` / `--ink-2`。
- **Hero 内容放大**：logo 144px、标题 clamp(36–46px)、状态与描述 15px、统计数字 34px、统计标签 12.5px；手机端收一档（120/34/13.5/30）避免拥塞。
- **底栏搜索浮层 P0 修复**：`fsUpdateActive()` 里的 `scrollIntoView` 会连带滚动 `.main-root`，导致搜索时整页被顶起约 480px；改为只滚浮层自身（`index.html` 内联脚本）。


### 2.4 节奏与细节
- 顶栏降噪：休息/天气/星象改成「无底色文字」，日期时间从等宽粗体降为 12.5px 表格数字；
- 底栏搜索与一言与纸面同材质，一言中文 13px、英文 11.5px；
- 短屏适配：1280×800 / 1366×720 下小游戏入口最多占 2 行（更矮 1 行），Mod 卡不再被裁掉下半截；
- 悬停去掉随机旋转、统一 2px 抬升；焦点环、`prefers-reduced-motion` 补齐。

### 2.5 审计回修（两位审计员第一轮）
- 社区天气卡 10.5px 小字对比度 4.14:1 → 提为 `--ink-2`（约 6:1）；页脚注释同步；
- 深色「我的」页暖棕脏底清理，深色账号卡与普通行恢复层级差；
- 深色登录遮罩、auth/各浮层暖棕投影统一为黑色系；
- 浮层圆角 26 → 24，popover 20，与卡片 22 / 内嵌 14 形成四级体系；
- 手机食谱分类 chips 右侧加渐隐；手机全屏发帖编辑器改不透明，消除底部色带；
- 空状态 `.cook-empty` 撑满内容区并垂直居中（含购物清单的内联 min-height 特例）。

### 2.6 布局层：手账拼贴（用户选定，桌面）
- 用户二选一后确定走「手账拼贴」：首页作为一页摊开的手账，左 1/3 封面（拍立得 logo + 手写标题 + 统计），右 2/3 拼贴（Mod 照片带、小游戏拍立得、便签目录工具、索引清单外设、社区/食谱票根），底部索引卡搜索 + 撕纸一言。
- 独立文件 `styles/citro-scrapbook.css` 最后加载；桌面 `≥1025×880` 生效，短屏自动回落 Bento，手机本轮不动。
- 纸张、装订边线、纸纤维、纸胶带、白边拍立得、KuaiLe 手写标签 + 橙色荧光笔底；深色为「夜手账」。
- 回退：删 `index.html` 里对应的 `<link>` 一行即可。详见 `docs/citro-手账布局说明.md`。

## 3. 还可以继续做的（按「更高级 / 更温馨」两条路线）

### 3.1 更高级（秩序与信息密度）
1. **首页减负**：把「外设驱动」整列移入 `#/res` 资源页；首页只留 8 个高频工具 + 3 个最常玩游戏。首页信息密度从 8 降到 5，高级感提升最明显。
2. **数字与时间统一**：`font-variant-numeric: tabular-nums` 全站化；若可引入一支中文可变字重字体（MiSans / HarmonyOS Sans / 思源黑体 VF），界面文字会比子集化 Noto 更挺。
3. **空态插画体系**：用 `素材/citro-logo.png` 的透明贴纸 + 手绘柑橘切片（单色线稿）做 3 张空态插图，替换现在的大面积空白与 emoji。
4. **动效只留一处**：Hero 光斑 8–12s 极慢呼吸（`prefers-reduced-motion` 关闭），其余交互动效保持 150–250ms。
5. **深色层次再走一步**：卡片/浮层/菜单分别用 3 个亮度台阶 + 顶部 1px 暖白高光；不要重新加彩色光晕。

### 3.2 更温馨（纸面与人味）
1. **纸纤维**：极低透明度（≤3%）的 200×200 SVG 噪点只铺画布、不铺卡片，避免当年「玻璃发脏」的问题。
2. **按时段问候**：Hero 状态行按早上/下午/深夜切换文案，并联动天气与节气（例如「霜降 · 记得添衣」）。
3. **手写体只出现在「人话」处**：空态提示、节日祝福、一言、按钮旁的一句小字；界面标签保持无衬线。
4. **节日色只动一个变量**：立秋/冬至/春节替换 `--accent` 与纸面暖光，不新增第二套组件。

> 边界：不要把社区入口卡改回大面积薄荷；不要在深色下加彩色背景光晕；不要用大玻璃模糊叠满屏；不要恢复「每张卡都描边」。
