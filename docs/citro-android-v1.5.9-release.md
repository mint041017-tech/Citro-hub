## 1. 极限刹车：3D 场景重写（含车模）

新增 `flutter/lib/games/gbrake_scene.dart`（世界 + 渲染器），`gbrake.dart` 整体重写玩法层：

- 渲染器与 web `index.html` 的 Canvas 透视投影逐段对齐：黄昏天空渐变 + 4 条漂移云带 +
  地平线暖光与太阳盘、两圈山裙、18 段雾化路面/路肩/路缘石、白黄标线 + 车道虚线 + 轮迹、
  夕阳反光带、路灯（45m 间距 + 灯头光晕 + 路面光池）、7 块指路牌、连续护栏 + 立柱、
  2600m 水马路障（橙白斜纹 + 「道路封闭 ROAD CLOSED」红板）。
- 车模 = web `GB_CARQ` 的 20 个低多边形面片（黑色车身 + 金色肩线 + 大后风挡 +
  行李架导轨 + 鲨鱼鳍天线 + 后视镜 + 镀铬饰条），按顶点叉积法线着色、面片渐变 +
  描边消缝、深度排序；四轮椭圆、⊓ 形尾灯（刹车增亮 + 路面反光）、绿牌「沪A·D1612F」、
  地面投影、夕阳轮廓光。
- 相机五模式（showcase 环绕 / chase 追尾 / brake 低贴 / crash 侧位 / finish 环绕）与
  平滑参数同 web；撞击慢动作（0.28× / 1.6s）、翻滚、烟尘、火花、速度线、暗角、白闪齐全。
- 物理/计分与 web `GB_*` 完全一致（起步 7.4 m/s²、260 km/h 封顶、力度 200+800·t N/s
  爬升 / 900 N/s 回落、1612 N 断裂、得分 = 初速度² ÷ 刹停用时，不再 ×8）。
- 流程补齐 3-2-1-GO 倒计时、速度表就绪变色（≥100 km/h 金→绿）与指针、踏板三态
  （灰 → 红脉冲「踩刹车!」→ 按下缩小「按住加力」）、结算四格数据 / 制动曲线
  （渐变填充 + 断裂虚线 + 终点标记）、得分滚动动画。

## 2. 2048

- 排行榜双分区：底部抽屉新增「玩家榜 / AI 榜」分段（web 同款固定 AI 名单 +
  十万分以上自动归 AI 榜，纯前端过滤、重排名次）。
- 修复「卡死概率」根因：贴墙原位合并（如 [2,2] 向左）时 `moved` 误判为 false，
  被合并的方块没被移除、棋盘出现幽灵方块持续翻倍；合并本身现在计为有效移动。
- 2 / 4 方块颜色重排层次（浅色 2→暖灰 / 4→金调 / 8、16 顺次加深；深色同步）。

## 3. 记忆卡牌

棋盘左右各收进 9px 内边距，卡牌不再贴游戏区边界，卡片按剩余宽度重排。

## 4. 淘气小球

- 红色预警加强：预警色按主题区分（浅色用 web 亮红 255,59,48），提高不透明度下限、
  加粗发光描边并内补一条不模糊实线，端点圆点加大。
- 「最高分」不再换行：游戏页统一钳制系统字号缩放（见第 7 条），pill 标签加
  maxLines:1 兜底。

## 5. 贪吃蛇

- 棋盘改为 Center 严格居中（去掉 OverflowBox 外溢与逐块 Transform 微移），任何
  机型宽度下左右对称。
- 结算浮层按钮间距上下对称（原来只补 top:10 导致内容整体偏上）。
- HUD 一行放不下自动换行（web .g-hud flex-wrap 行为），窄屏不再挤出屏幕。

## 6. 羊了个羊

恢复「正在玩」模块（v1.5.8 误关 showLive），进度文案与 web 一致：
「第 N 关 · 剩 X 张」；页面高于视口时按 web 行为进滚动流。

## 7. 成语接龙 / 飞花令

- AI 兜底接通：玩家提交词库外成语/诗句时改为走 `AiService.verifyIdiom/verifyPoem`
  （glm-5.3-flash）判定，通过即接受并显示「AI 判定中…」；不再一律回
  「不在本地词库」。AI 回合、结算胜负音效同步接入。
- 开始按钮与规则重叠修复：a) 游戏页统一 `textScaler: noScaling`——系统字号放大
  会把规则/HUD 文本撑出定版式（「最高分」换行同源）；b) 成语接龙菜单的按钮与
  AI 提示行整体下移 18px，Skia 字形度量下规则比 web 高约 12px 的固有偏差不再
  压住第四条。

## 8. 数织

「再来一局」按钮恢复内容自适应宽度（内层 Center 会撑满浮层宽度的 bug，
`widthFactor: 1` 修复）。

## 9. 游戏页头像

游戏页顶栏账号圆钮（`_MeButton`）在登录态显示用户真实头像（web gamesRenderMe
行为），未登录仍显示昵称末字。

## 10. 全局音效与震动

新增 `flutter/lib/services/game_sfx.dart`：

- Dart 直接合成 16bit PCM WAV（方波/锯齿/三角/正弦 + 噪声脉冲，44.1kHz），
  audioplayers 播放，6 播放器轮转 + 参数缓存，零音频资源；引擎/轮胎为循环源，
  支持播放速率与音量实时调节（极速刹车专用）。
- 震动走 `HapticFeedback`（selectionClick / light / medium / heavy），无需权限。
- 静音开关持久化（`citro_game_mute`），极限刹车菜单「音效：开/关」接入；
  测试环境自动禁用。
- 接入点：2048（移动/合并/胜负）、记忆卡牌（翻/配/失配/通关）、贪吃蛇（吃/终局）、
  羊了个羊（选牌/三消/失败/通关 + 道具）、淘气小球（反弹/新缺口/出界）、跳一跳
  （落块/完美/坠落）、数独（填对/填错/成败）、华容道（移动/还原）、数织
  （填/标/完成）、成语接龙与飞花令（提交/AI 回合/胜负）、极限刹车（倒计时/踩刹/
  撞击/胜利/引擎与轮胎循环）。

## 构建注意（沿用 v1.5.8）

- 中文路径必须先 `subst X: "C:\网站web\Citro"`，在 `X:\flutter` 下 `flutter clean`
  后再构建（`flutter analyze` 在中文真实路径下 analysis server 直接崩退）。

- 密钥：`密钥/glm.key` → `--dart-define=GLM_API_KEY=...`，不进仓库。
