# Citro 1.9.8 更新日志

2026-10-30 · 版本 1.9.8（Android versionCode 1908）· Web / Windows / Android / iOS 源码同步

1.9.8 收尾听隅交互，并统一四端动效与页面转场；同时把 1.9.6–1.9.8 累积的卡面收藏、CiCi 图片消息、铃渡、数独二版、果冻 Q 弹等内容统一进四端源码与制品。

## 听隅

- 番茄钟按钮改回 38px 圆形：空闲显示计时器图标，计时中圆内显示剩余 `mm:ss`；按钮与时钟紧贴。
- 「收藏」页标题与排序固定在顶部，配方列表单独滚动。
- 呼吸换相提示音改为极轻的短音：0.42 秒、音量 0.1、近纯音，不再使用明显铃声。
- 离开听隅后仍播放时提供统一播放入口：手机/平板/Windows 首页听隅圆形入口变为胶囊（混音标题 + 暂停），Web 桌面在主题旁显示同一胶囊；点胶囊回听隅，暂停后恢复圆形入口。
- 安卓多轨修复：六路播放器与提示音统一使用 `mixWithOthers` 音频焦点，不再出现「慢慢入夜」只有一部分声音在响。

## 动效与交互

- 新增 `CitroMotion` 统一曲线与时长：页面/弹层/按钮/Toast 使用同一套强 ease-out 参数。
- 页面转场统一短时长：Android 由 450ms 缩短到 220ms，iOS/macOS 保留 Cupertino 边缘返回手势，Web 160ms、Windows 160ms。
- 全局 Toast 改为淡入下移进场、同路径退场；首页听隅入口与播放胶囊之间加入尺寸与透明度过渡。
- 适配系统「减少动态」：页面转场退化为淡入，Tab 切换直接切页，Pressable 不做位移/缩放，弹层与 Toast 去掉位移。
- 主题切换改为 ease-out 200ms；Pressable 的按压/悬停反馈统一曲线。

## 1.9.6–1.9.7 累积内容

- 卡面收藏与每日抽卡：111 张卡面、收藏库、每日打卡/转运/游戏/动态/菜谱/CiCi 抽卡机会。
- CiCi：圆形头像、图片消息、更严格的善举审核（需真实助人或捐赠截图）。
- 铃渡（Knockwater）：原生 Flutter 并入，标准游戏骨架、关卡解锁、排行榜与正在玩。
- 数独二版：风车/3D 三面/2·3·13 布局等变体、笔记联动、暂停全屏遮挡、撤销。
- 咕噜果冻：Q 弹软体、贴紧必合、撑爆罐子判负、阶段式出货权重。
- 深色模式、手机左右滑动切页、「我的」页按平台重排、iPad/Windows 宽屏壳层优化。

## 修复

- 安卓听隅多轨只剩部分声音；提示音抢占音频焦点。
- 听隅收藏标题滚动后消失；番茄钟按钮与时钟距离过远。
- Web 端主题旁播放控件出现/消失过硬、首页入口尺寸跳变。
- 数独弹窗按钮分布、CiCi 输入框文字错位、记忆卡牌深色卡背过亮等既有问题。
