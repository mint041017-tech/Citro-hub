## 本版食谱日记改动

1. **封面裁切与位置**：选图后进入 1:1 裁切浮层，可拖动/双指缩放；封面框移到菜名输入框与来源链接框之间，居中展示，可重复裁切。
2. **热量口径**：向导、食谱卡、详情、复制文本统一改为「千卡 / 100g」，字段仍存 `calories`，兼容旧数据。
3. **分量选择**：几人份改为 1–12 的选择菜单（底部弹层），不再是数字输入框。
4. **食材合并与用量**：主料/辅料合并为「食材」，与「调料」并列；食材行放大（名称 44dp、删除 38dp），用量改为先选单位（g/kg/克/斤/ml/L/个/只/根/片/勺/碗/把/包/瓶/罐/杯/适量/自定义），再填数量；旧数据会自动解析原用量。
5. **步骤按钮**：图库改名为「图片」，移除拍照按钮；图片、计时、删除按钮放大，步骤输入框与图片预览同步加大。
6. **购物清单**：每条右侧删除按钮放大为 32dp 圆形点击区，图标 15dp。
7. **吃什么布局**：抽选结果框由铺满改为固定 170dp，面板高度收至屏高 64%；分类按钮保持加大；「吃什么」Tab 移到中间并使用薄荷绿区分。
8. **封面加载**：食谱卡/找菜缩略图按显示尺寸解码（cacheWidth）、增加占位与淡入，并在列表数据到达后预取前 10 张封面，减少打开食谱日记时的空白与解码卡顿。

## 构建

```powershell
subst Q: "C:\网站web\Citro"
cd Q:\flutter
$env:GLM_API_KEY = (Get-Content ..\密钥\glm.key -Raw).Trim()
flutter build apk --release --dart-define=GLM_API_KEY=$env:GLM_API_KEY
```

产物复制为 `APK/Citro-v1.5.0-release.apk`，用 `aapt dump badging` 与 `apksigner verify` 复核。
AI 密钥只保存在本地 `密钥/glm.key`，不写入源码；客户端直连密钥会编入 APK，公开分发前建议改为服务端代理。
