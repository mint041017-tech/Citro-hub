# Citro 2.1.0

> 版本号：`2.1.0+2100` · 2026-11-09
> 汇总区间：2.0.15 → 2.1.0（按功能模块汇总）

## 首页与手账

- 首页卡片支持自由编排：拖拽移动、按住缩放、内容面板添加/删除，
  手机、平板、Windows 各自保存横竖屏布局。
- 新增迷你卡档位：日历、待办、记账、心情等卡片缩到 3×2 时自动切换为只显示
  今日关键信息，避免小尺寸里塞满小字。
- 日历卡：小卡只保留今天（年月 + 农历日 + 大日期 + 事件卡），点击整卡进入
  完整日历详情页；月历中的倒数日/纪念日会显示小圆点。
- 待办卡：改为「主指标 + 进度 + 任务列表 + 小票指标块」，小卡显示剩余件数、
  完成率、专注与连续天数，大卡自动列出更多任务。
- 记账卡：改为「主金额 + 收入/结余 + 进度 + 指标块」，小卡补充本月支出、
  预算、收入与笔数，大卡分类列表带金额。
- 手机端首页顶部留白收紧，不再与状态栏重叠；全屏页与首页保持同一套顶部边距。

## 待办

- 新增完整待办模块：任务（待办 / 进行中 / 已完成）、清单、分类、优先级、
  截止时间、提醒与子任务。
- 今日看板、日程日历、每日复盘、心情记录。
- 专注模式与番茄钟打通，首页显示今日专注分钟与连续完成天数。
- 修复同一微秒内连续创建任务时 id 可能重复、导致任务互相覆盖的问题。

## 记账

- 新增完整记账模块：账单、分类、月度预算、收入目标、结余与储蓄率。
- 首页记账卡三档尺寸、月历支出、近 7 日柱图、分类 Top 与预算进度。
- 支持手动记账、截图识账草稿确认、CiCi 看账与预算建议。
- 新增 `/api/ledger` 整包云端同步。

## 日历

- 新增日历详情页：整月月历、选中日期详情、农历/节气/节日。
- 新增倒数日 / 纪念日：支持每年重复、备注、编辑删除；
  通过 `/api/calendar` 按账号云端同步，离线时显示「仅本机」。
- 农历显示：小卡顶部年月行直接显示农历日（初一、廿一、三十等）。

## 社区与 CiCi

- 评论时间固定到评论右上角，长昵称或「回复 @」不会再挤走时间。
- 扫码登录、手机端扫一扫、登录子标签居中、主题下拉重做（延续 2.0.14/2.0.15）。
- CiCi 支持自定义性格，社区评论与回复更自然；有人回复 CiCi 时会继续对话。
- 社区通知走前台轮询 + 本地通知；退后台暂停轮询，回前台补一次。

## 听隅与专注

- 白噪音多轨混音、声景与专注/休息计时。
- 番茄钟到点提醒、计时胶囊、后台/被遮挡时暂停刷新。

## 食谱日记

- 食谱库、广场、找菜、购物清单、冰箱食材、时间滚轮与食材选择器。
- 食谱封面与步骤图、计时器与空状态全部统一手账风格。

## 四端与性能

- Android / iOS / Windows / Web 共用 Flutter 页面与业务逻辑。
- 全局 120Hz：`RefreshRate.acquire()` 常驻，iOS ProMotion 配置保持。
- 列表懒加载、图片 `cacheWidth` 解码、`RepaintBoundary`、低内存回调。
- 首页日历格不再逐格套 `Opacity`，改用颜色 alpha，减少离屏合成。
- 日历/记账底部弹层移除 `shrinkWrap`，避免全量测量。
- 退后台取消 60 秒轮询 Timer，回前台重建，降低待机耗电。
- 清理未使用 import / 变量，`flutter analyze` 保持 0 error / 0 warning。

## 安全与稳定性

- 修复 CORS 无条件反射 Origin + Allow-Credentials 的高危问题，改为域名白名单。
- 反向代理真实 IP 优先 `X-Real-IP`，XFF 取最后一段，避免伪造 IP 绕过限流。
- 图片/语音文件名改用加密随机数，降低枚举与并发覆盖风险。
- Android 关闭 `allowBackup`，避免本地 token 与数据被系统备份导出。
- 内置浏览器只浏览站内域，站外链接改由系统浏览器打开。
- 登录/注册、发帖、评论、上传等接口保持频率限制与请求体大小上限。
