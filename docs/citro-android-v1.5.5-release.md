## 社区

1. **头像进入发布页**：移除「全部动态」「我的发布」筛选按钮；点击自己封面头像打开「我的发布」，点击他人动态头像打开「TA 的发布」（底部弹层，含头像、昵称、动态数与获赞数，可点赞/评论/删除自己的动态，关闭后主列表自动刷新）。匿名动态头像不可点。
2. **搜索移位**：搜索按钮从筛选行移到收件箱右侧（收件箱在左、搜索在右），点击展开/收起搜索框。

## 评论输入

3. **失焦自动收起**：评论输入框失去焦点（点击卡片其他区域、点赞、翻评论等）时自动收起，回复引用一并清空；发送成功后也会收起。
4. **框内按钮保护**：点输入框旁边的图片/录音/发送按钮不会再误触「收起」，选图器能正常打开；选图或结束录音后输入框自动重新聚焦。

## 食谱日记

5. **食材数量步进器**：新建/编辑食谱的食材与调料数量改为 `− 值 +` 步进器（中间数值可直接点按输入小数），步进器与单位胶囊统一居左排列；免数量单位（一小把/少许/少量/适量/不用单位）保持纯提示。
6. **冰箱数量步进器**：找菜 → 我的冰箱的添加/编辑食材弹窗中「数量」同样改为步进器。

## 计时与通知

7. **计时胶囊去下划线**：胶囊浮层补上 `TextDecoration.none`，去掉倒计时和名称下方系统兜底样式的黄色双下划线。
8. **常驻通知倒计时放大**：计时进行中的通知改用自定义 RemoteViews 布局——`⏳ 计时中` 标题 + 30sp 大号倒计时（Chronometer，正确换算 elapsedRealtime 时基）+ 菜谱名；通知被划掉后倒计时仍由系统继续，到点由同一 ID 的「时间到」提醒替换。

## 其他

9. **发动态图片防闪烁**：发布动态的图片预览改为一次性持有字节与 provider，逐字输入触发重建时不再反复解码导致闪烁。
10. **更改信息生日选择器**：我的页 → 更改信息中生日（公历）的月/日由系统 DropdownButton 换成手账风格选择框 + 底部滚轮弹层（出生月份/出生日期），样式与计时分钟选择一致。
