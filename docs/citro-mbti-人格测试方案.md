# Citro 16 型人格测试功能 · 详细方案

> 版本：v1.0（2026-11-19）
> 状态：待评审
> 核心要求：**测试尽量准确，解释尽可能清晰**

---

## 1. 背景与目标

Citro 目前已有星象、每日一言、小游戏、社区等轻量自我探索 / 娱乐模块，人格测试与产品调性高度契合，且自带强分享传播属性（四字母标签、结果卡片），能为社区带来 UGC 话题。

**目标：**
1. 上线一个免费、无需注册即可作答的 16 型人格测试，结果稳定、可解释、可复测。
2. 报告让完全不懂心理学的人也能看懂，且"读完觉得说的是我，而不是谁都适用"。
3. 结果可分享（图片卡片）、可留存（历史记录）、可浏览（16 型图鉴）。

**非目标（明确边界）：**
- 不做心理诊断、不用于招聘选拔、不做付费"专业认证报告"。
- 不宣称"官方 MBTI"，不复制任何现有量表的题目（详见 §9 合规）。

## 2. 调研结论

### 2.1 准确性：MBTI 类测试的真实水平

| 证据 | 结论 |
| --- | --- |
| 官方 Form M 手册数据 | 4 周重测约 65% 的人四字母完全相同，93% 的人至少三个字母相同；连续维度分重测相关较高 |
| 学界批评（针对旧版 Form G 及二分法） | 早期研究约 50% 的人 5 周后类型变化；**变化集中在"贴线"维度**——得分越靠近中点，重测翻转越常见 |
| 与 Big Five 的相关研究（McCrae & Costa 1989 等） | E/I↔外向性、S/N↔开放性、T/F↔宜人性、J/P↔尽责性有实质相关，说明四个维度测的是真实存在的人格特质 |
| 巴纳姆效应批评 | 模糊、普适、只夸不贬的描述会让人对任何结果都点头，**这是文案问题，可以通过写作规范解决** |

**对本方案的三条指导：**
1. **放弃"非黑即白"的二分呈现**：每个维度输出连续分数（百分比），贴线维度必须明确标注"倾向不明显"，而不是硬塞一个字母。
2. **准确性主要靠题目质量与作答质量控制**，不是靠堆题量：情境化行为题、反向题平衡、一致性检测、作答时长检测。
3. **结果页给用户一次"校准"机会**：贴线维度展示两种倾向的对比描述，让用户自己确认哪个更像——这与官方手册"施测后由本人验证类型"的做法一致，是提升最终准确率最有效的一步。

### 2.2 竞品形态

| 产品 | 模型 | 可借鉴 | 需避开 |
| --- | --- | --- | --- |
| The Myers-Briggs Company（MBTIonline） | 官方 MBTI Step I/II，付费（约 $50+），无免费版 | "测后由本人确认类型"的流程；连续分数呈现 | 商标、题目、报告均不可碰 |
| 16Personalities | 自研 NERIS 五维模型（四维 + Identity：-A/-T），7 点同意度量表，百分比结果 | 答题交互（一屏一题/一组题、进度条）、结果页分层结构、第五维度的加入 | 它是独立模型而非官方 MBTI；其题目、16 型中文昵称（如"提倡者"）、插画风不可复制 |
| Sakinorva | 荣格八维认知功能路线，题量大、术语密集 | 八维分数雷达图作为进阶内容 | 全术语输出对小白不友好，不能直接照搬 |

### 2.3 理论选型

- **主模型：经典四维度**（E/I、S/N、T/F、J/P）→ 16 型。认知功能栈（荣格八维）只作为**结果解释层的进阶内容**，由四字母推导展示，**不单独出一套八维计分**——避免"八维测试结果和四维结果打架"这一同类产品的常见翻车点。
- **加分项：第五维度"情绪稳定 / 情绪敏感"（对应 16P 的 -A/-T）**。它与神经质维度对应，能显著提升报告的"懂我"程度，且与四维度正交、不干扰 16 型判定。作为实验性维度标注展示。

## 3. 产品方案

### 3.1 定位与命名

- 功能名：**「人格测试 · 16 型」**（页面副标题："基于荣格心理类型理论的自研问卷"）。
- 全文避免将 "MBTI" 作为产品名或宣传语；科普性提及（如"与 MBTI 同样源自荣格类型理论"）可以保留，但需附声明（§9）。
- 入口：**首页 Bento 卡片作为主入口**，固定排在「每日一言」上方（宽屏第 14 行、窄屏第 16 行，整宽 2 行；可编排、可移除）。测过之后卡片直接显示最近一次的类型与昵称。点按采用与「听隅」相同的打开方式：卡片纸面自身展开为整页（`CitroCardMorph`），返回时沿同一轨迹缩回卡片原位。资源库「实用工具」保留一个次级入口。

### 3.2 测试版本

| 版本 | 题量 | 时长 | 精度定位 |
| --- | --- | --- | --- |
| 快速版 | 28 题（每维 7） | 约 3 分钟 | 结果页显著标注"简版，建议做完整版"，贴线阈值更宽 |
| **标准版（默认）** | **64 题（每维 16）** | **约 8 分钟** | 主推版本 |
| 完整版（二期） | 96 题（每维 24，含第五维度 16 题） | 约 12 分钟 | 含情绪维度与更细分面报告 |

一期只做快速版 + 标准版，共用同一题库池（快速版 = 每维抽取固定子集），避免维护两套题。

### 3.3 用户流程

```
入口页（功能简介 / 时长 / 版本选择 / 作答须知）
   ↓
答题页（一屏 4 题，7 点量表，进度条，可回退修改）
   ↓
作答质量检测（时长 / 直线作答 / 一致性题对）→ 异常则温和提示，不阻断
   ↓
计分（本地完成，无需联网）
   ↓
结果页 · 第一层：类型卡 + 四维条形图（含贴线标注）
   ↓
结果页 · 第二层：分维度"像不像我"自评校准（贴线维度强制展示双描述对比）
   ↓
完整报告（优势 / 盲点 / 场景解读 / 认知功能栈 / 成长建议）
   ↓
保存历史（本地 + 登录可选同步）/ 生成分享卡片 / 浏览 16 型图鉴
```

## 4. 题库设计（准确性的核心）

### 4.1 维度与子维度（facet）

每个维度拆 3 个子维度，保证覆盖该维度的不同行为侧面，避免"用一个侧面代表整个维度"：

| 维度 | 子维度 | 测量内容举例 |
| --- | --- | --- |
| E / I 精力来源 | 社交激活 | 聚会后是兴奋还是疲惫 |
| | 表达节奏 | 边说边想 vs 想好再说 |
| | 独处需求 | 周末偏好社交安排还是独自恢复 |
| S / N 信息偏好 | 细节与事实 | 关注"具体发生了什么" vs "这意味着什么" |
| | 经验与可能 | 信赖已验证的方法 vs 喜欢尝试新路径 |
| | 抽象兴趣 | 对理论、隐喻、未来构想的自发兴趣 |
| T / F 决策方式 | 逻辑优先 | 评判方案先看对错与利弊 vs 先看相关人的感受 |
| | 冲突表达 | 指出问题时直接程度 |
| | 共情反应 | 朋友倾诉时先给方案还是先安抚 |
| J / P 生活方式 | 计划性 | 出行前做攻略的程度 |
| | 截止压力 | 提前完成 vs 死线爆发 |
| | 环境秩序 | 桌面 / 日程 / 物品的条理性 |

### 4.2 题目写作规范（每条都要遵守）

1. **写行为，不写标签**。❌"你是一个外向的人吗？" ✅"连续社交两天后，你通常需要一段独处时间才能恢复精力。"
2. **写具体情境，不写抽象特质**。❌"你注重细节。" ✅"回忆一次旅行时，你最先想起的往往是具体的画面和细节，而不是整体感受。"
3. **两端对等，不暗示优劣**。任何一端的表述都不能显得"更成熟/更聪明/更正常"。
4. **避免双重否定、避免一题两问、避免绝对词**（"总是""从不"只用于反向质检题）。
5. **文化语境原生化**：情境用中文用户日常（饭局、群聊、ddl、租房、开黑），不翻译腔。
6. **反向题约占 40%**：同一维度内正反向混合，降低"一路点同意"的默认偏差。
7. 每题只归属一个维度一个子维度；不跨维度混合（如"你喜欢深入分析他人的动机"同时碰 N 和 F，弃用）。

### 4.3 示例题目（7 点：很不同意 → 很同意）

| 维度 | 方向 | 题目 |
| --- | --- | --- |
| E/I | 正向（偏 I 计分示例） | "在热闹的聚会上，我通常是越聊越兴奋，而不是越待越累。"（反向计分） |
| E/I | 正向 | "遇到问题，我习惯先自己想一想，再决定要不要和别人讨论。" |
| S/N | 正向（偏 N） | "听到一个新观点时，我会不自觉地联想到它还能用在哪些别的地方。" |
| T/F | 正向（偏 F） | "朋友向我倾诉烦恼时，我的第一反应是安慰，而不是分析该怎么办。" |
| T/F | 反向 | "指出别人方案里的漏洞时，我几乎不会顾虑对方的面子。" |
| J/P | 正向（偏 P） | "计划被打乱时，我通常觉得无所谓，随时能换一套玩法。" |

> 完整题库（标准版 64 + 扩展 32 = 96 题）作为独立交付物 `questions.json`，单独评审；每题需通过"双人背对背标注维度归属一致"才入库。

### 4.4 作答质量控制

| 机制 | 规则 | 处理 |
| --- | --- | --- |
| 作答时长 | 总时长 < 题量 × 1.5 秒 | 结果页提示"作答较快，结果可能不准，建议认真重测"，不阻断 |
| 直线作答检测 | 同一选项连续 ≥ 12 题，或单选项占比 > 80% | 同上提示 |
| 一致性题对 | 每维埋 1 对语义相近、表述不同的题（共 4 对） | 题对答案差 ≥ 4 档记 1 次矛盾；≥ 2 次矛盾时结果页标注"本次作答一致性较低" |
| 反向题校验 | 正反向题得分严重背离（内部一致性低） | 并入一致性提示 |

**所有质检只做提示、不做拦截**，保证体验顺畅；质检结果写入历史记录，供用户复测对照。

## 5. 计分算法

### 5.1 维度分

- 每题作答值 `a ∈ {1..7}`（很不同意=1 … 很同意=7）。
- 正向题（同意代表偏右端字母，如 I/N/F/P）计 `s = a - 4`；反向题计 `s = 4 - a`。单题得分域 `[-3, +3]`。
- 维度原始分 `D = Σs / (3n)`，归一化到 `[-1, +1]`，n 为该维题数。
- 展示百分比：`左端% = round((1 - D) / 2 × 100)`，右端% = 100 - 左端%。例如 E 62% / I 38%。

### 5.2 贴线与置信度（准确性的关键呈现）

| `|D|` 区间 | 判定 | 呈现 |
| --- | --- | --- |
| ≥ 0.35 | 倾向明确 | 直接给字母，条形图高亮 |
| 0.15 ~ 0.35 | 倾向中等 | 给字母 + "倾向温和"标签 |
| < 0.15 | **贴线** | 字母以浅色 / 空心显示，标注"倾向不明显"，报告同时提供两端描述，并引导自评校准（§3.3） |

- 四字母照常输出（传播需要），但结果页必须有一句："字母只是坐标，百分比和具体描述比字母本身更重要。"
- 快速版贴线阈值上调至 0.20。

### 5.3 自评校准

结果页逐维度问"这个描述像你吗？"（像 / 不太像 / 说不好）。贴线维度额外展示左右两端各一段行为化描述，用户可点选"更像这边"。
- 用户确认后的类型记为"确认版"，与"作答版"并存展示；两者不同则并列说明（"你的作答结果是 INFP，你自评更接近 ISFP"）。
- 这一步能实质修正贴线误判，也是官方流程里"类型验证"的等价物。

### 5.4 第五维度（二期）

情绪稳定(-A) / 情绪敏感(-T)：独立计分，附加在类型后（如 INFJ-T），只影响报告中的压力反应与情绪章节，不影响四字母。

## 6. 报告与解释体系（清晰度的核心）

### 6.1 报告分层结构

1. **一句话画像**：类型昵称 + 一句具体、有画面的总结。
   > 例（INFP）："心里有一套很完整的价值标尺，平时安静，碰到在乎的事会突然较真。"
2. **四维条形图**：每条附 2 行白话解释 + 贴线标注。
3. **你的优势（3~4 条）**：每条 = 特质 + 具体行为示例。
4. **容易踩的坑（3~4 条）**：与优势同源（"优势的过度使用"），语气不对立、不贩卖焦虑。
5. **场景解读**：学习/工作、恋爱与亲密、朋友与社交、压力下的自己，各一段。
6. **认知功能栈（进阶，可折叠）**：见 §7。
7. **成长建议（2~3 条）**：可执行的小行动，非鸡汤。
8. **边界声明**：固定文案，见 §9。

### 6.2 反巴纳姆文案规范（"清晰且准"的关键）

- **每条描述必须带一个可对照的具体行为**，让用户能验证"我是不是这样"，而不是一句漂亮的空话。
  ❌"你内心丰富，渴望被理解。"（人人都适用）
  ✅"群聊里你更多是潜水，但和熟人一对一聊喜欢的话题时，能连续聊很久。"
- **每条配一句反向边界**："这并不意味着……"（如"偏内向不等于社恐，你只是更在意社交的性价比"）。
- **优势与盲点对等**，不写纯夸报告；不做人身定性（避免"你天生不适合……"）。
- 不预测命运、不诊断疾病、不评判"好坏类型"。
- 全文术语首次出现必配白话注（如"J（判断）= 偏好有计划、有定论的生活，不是'爱评判别人'"——这是最常见的误读，必须专门解释；同理 P≠没原则、F≠不理性、N≠不着调）。

### 6.3 16 型图鉴

- 16 个类型各一份内容包：昵称（自研）、关键词、四段场景文案、功能栈、代表色。
- 图鉴页 4×4 宫格（分析家/守护者等分组可自研命名），未测试用户也可浏览，形成传播与回流。
- 每型配一张简洁插画 / 符号卡（沿用 nosh 视觉风格，不用 16P 小人风格）。

## 7. 认知功能栈（进阶解释，一期可折叠）

由四字母按规则推导，无需额外题目：

| 类型 | 主导 → 辅助 → 第三 → 劣势 |
| --- | --- |
| ISTJ / ISFJ | Si-Te-Fi-Ne / Si-Fe-Ti-Ne |
| INFJ / INTJ | Ni-Fe-Ti-Se / Ni-Te-Fi-Se |
| ISTP / ISFP | Ti-Se-Ni-Fe / Fi-Se-Ni-Te |
| INFP / INTP | Fi-Ne-Si-Te / Ti-Ne-Si-Fe |
| ESTP / ESFP | Se-Ti-Fe-Ni / Se-Fi-Te-Ni |
| ENFP / ENTP | Ne-Fi-Te-Si / Ne-Ti-Fe-Si |
| ESTJ / ESFJ | Te-Si-Ne-Fi / Fe-Si-Ne-Ti |
| ENFJ / ENTJ | Fe-Ni-Se-Ti / Te-Ni-Se-Fi |

展示方式：不用八术语堆砌，用"你的内在工作方式"叙事，例如 INFJ：
> "你习惯先在脑子里把人和事的走向想明白（内倾直觉 Ni），再对外照顾氛围与他人感受（外倾情感 Fe）；累到极点时，可能突然放纵吃喝或冲动消费（劣势 Se 的反弹）。"

## 8. 技术实现

### 8.1 总体架构

**纯本地可完成核心闭环**，后端只做可选同步，符合现有 Node 零依赖架构：

```
flutter/assets/mbti/
  ├─ questions.json      # 题库（96 题全量：四维各 20 + 情绪维度 16）
  └─ types.json          # 16 型内容包（昵称/画像/优势/盲点/场景/功能栈）
flutter/lib/mbti/
  ├─ models.dart         # 题库/类型包模型与加载（含测试注入 debugRaw）
  ├─ scoring.dart        # 维度分、贴线分档、作答质检（纯函数，可单测）
  ├─ copy.dart           # 维度白话解释、两端校准描述、边界声明
  ├─ store.dart          # 本地历史（收藏/回写/删除，最多 30 条）
  ├─ ai.dart             # GLM 个性化解读（失败静默降级）
  ├─ report.dart         # 维度条、类型头卡、完整报告、图鉴、历史页
  ├─ mbti_page.dart      # 入口 / 答题 / 结果与自评校准
  └─ home_card.dart      # 首页 Bento 入口卡片（显示最近结果）
flutter/test/
  ├─ mbti_scoring_test.dart      # 16 组计分/质检/边界用例
  ├─ mbti_flow_test.dart         # 标准版全流程 + 贴线校准
  ├─ mbti_quick_flow_test.dart   # 快速版 + 作答质量提示
  ├─ mbti_gallery_test.dart      # 图鉴入口与类型详情
  └─ mbti_home_card_test.dart    # 首页卡片空态 / 有结果态 / 打开与关闭
```

- **计分纯 Dart 本地完成**，答题不联网；结果默认只存本地。
- 登录用户可选同步：`trash/trash.js` 新增 `POST/GET /trashapi/api/mbti/results`，JSON 落盘（沿用现有用户数据目录约定），仅保存类型、维度分、时间，**不保存逐题答案**（最小化隐私面）。
- 分享卡片：`RepaintBoundary` 截图生成 PNG（类型 + 昵称 + 四维迷你条形图 + 二维码/站点名），一键保存/分享。

## 10. 验证与迭代（让"准确"可持续）

1. **内测（上线前）**：招募 ≥ 30 人做标准版，间隔 2~4 周重测：
   - 各维度内部一致性（Cronbach's α ≥ 0.7 为合格，低于则淘汰/改写低区分度题）；
   - 重测后"确认版"类型一致率目标 ≥ 80%（四字母全同不作硬性要求，贴线维度单独统计）；
   - 每题区分度（高低分组差异）筛查，淘汰与所属维度总分相关 < 0.2 的题。
2. **上线后匿名统计**（需用户同意）：各维度分布、贴线率、自评改判率、复测率。自评改判率高的题目优先修订。
3. **题库版本化**：`questionVersion` 写入每条历史，版本间结果对比页注明"题库已更新，分数不直接可比"。
