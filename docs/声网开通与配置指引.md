# 声网 Agora 开通与配置指引

按下面步骤走完，拿到两个值（App ID + App Certificate），交给我就完成接入 —— 代码已经全部写好，配好证书即生效，不用再改代码。

## 1. 注册账号

1. 打开 https://sso.shengwang.cn/cn/Signup （声网国内站，手机号注册即可，送每月 **1 万分钟免费额度**）
2. 完成手机验证后进入「控制台」。

> 用国内站（shengwang.cn），不是国际站（agora.io）—— 国内站的服务节点在国内，延迟低；两个站的账号不通用。

## 2. 创建项目拿凭证

1. 控制台 →「项目管理」→「创建项目」
2. 项目名随便填（如 `citro-share`），使用场景选「直播」或「互动娱乐」，鉴权方式**必须选 App ID + App Certificate（安全模式）**
3. 创建完成后，点开项目详情页，能看到：
   - **App ID**（32 位十六进制，如 `a1b2c3d4...`）
   - **App Certificate**（32 位十六进制，点「启用」后显示；只显示一次，记下来）

## 3. 把两个值交给 Worker（两种方式任选）

**方式 A：发给我，我来配置**（推荐，最省事）
把两个值发我，我执行：

```bash
cd C:\webflu\Citro\screen-share
npx wrangler secret put AGORA_APP_ID
npx wrangler secret put AGORA_APP_CERT
```

**方式 B：自己配**
在本机命令行运行上面两条命令，按提示分别粘贴 App ID / App Certificate，回车即可。

## 4. 验证生效

配置完成后（不用重新部署 Worker，secret 即时生效）：

```bash
curl -s https://share.mint1017.cn/api/health
```

然后用 App 创建一个一起看房间，App 观众端看 `adb logcat` 里出现：

```
Agora 链路已接入（host=true/false uid=…）
```

网页观看端开 DevTools Console，出现 `[agora] joined as audience` 即成功。

## 链路行为（已实现，无需操作）

| 场景 | 行为 |
|------|------|
| 配了证书 | 媒体走声网 SD-RTN（国内节点直连），延迟显著低于 Cloudflare |
| 没配证书 | 自动走 Cloudflare（现状不变），App/Web 都无感 |
| 声网连接失败 | 自动回落 Cloudflare 链路，房间不中断 |
| Web 端 | SDK 从 download.agora.io 加载（国内可直连），失败同样回落 |
