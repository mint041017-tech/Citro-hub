# Citro 毛玻璃层说明（2026-10-19）

> 需求口径：站长的原话——「我的网站在升级前是有毛玻璃效果的，我想给新版本的卡片加上一些毛玻璃效果」。
> 追加口径（同日）：「都没透视到下层的网格」→ 桌面手账/Bento/手机都要能隔着玻璃看见纸面方格；
> 「毛玻璃效果不要有白边」→ 玻璃卡不再用白色描边，只留阴影与顶部内高光。
> 实现文件：`styles/citro-glass.css`（`index.html` 中最后加载的一层皮肤，只做材质与氛围，不改任何结构）。
> 回退：删掉 `index.html` 里 `<link rel="stylesheet" href="styles/citro-glass.css">` 一行即可回到改版前的实色纸卡。

---

## 1. 做了什么

升级后的 Citro 视觉是「奶油纸 + 实色卡」，卡片背景接近不透明（`rgba(248,242,229,.86~.92)`），
虽然很多卡片/浮层本来就有 `backdrop-filter`，但被自己的底色盖住，看起来仍是实心。这一层做五件事：

1. **把卡片变成真玻璃**：半透底 + 背景模糊 + 饱和增强，让底下的纸纹、方格、水彩光斑透上来；
   但模糊半径刻意压到 **1.2–5px**（桌面 1.2px、手机 5px，见 §2），远低于方格间距（32px），这样 1px 的网格线
   被柔化而不会被高斯模糊抹平——这是「隔着毛玻璃还能看见格子」的关键。
2. **给玻璃可透的内容**：浅色在奶油底上叠柑橘橙 / 鼠尾草绿 / 蜜桃色水汽与两圈极淡的柑橘切片水纹，
   并在全局画布与手账纸页上铺 32px 手账方格；深色在近黑底上补几团极淡的暖光与暗格。无照片壁纸。
3. **去掉白边**：所有玻璃卡的 1px 白色描边改成透明（`--g-line` / `--glass-line` 均为 `transparent`），
   卡片只用「暖色长投影 + 顶部 1px 内高光 + 底部内暗影」定义体积；弹层边改成极淡暖色而不是白边。
4. **统一材质语言**：首页 Bento、桌面手账、社区、食谱、我的、搜索/抽奖/灵敏度、游戏页侧栏与排行榜、
   弹层，全部用同一套玻璃令牌，浅/深各一套；内层小卡只做半透平涂，不重复 blur（避免「糊叠糊」）。
5. **弹窗也全部玻璃化**：登录/注册、资料、赞赏码、番茄钟、运势/星盘、天气、笔记、吃什么、跳转确认、
   封面裁切、时间滚轮、食材库、食谱弹层、搜索建议、账号/通知/主题/食谱菜单、游戏结算/暂停层，
   统一 `--g-pop-bg`（68%/72% 通透）+ 26px 模糊 + 顶部受光，并叠一点主题色（右上暖橙 .18 / 左下鼠尾草 .12），不是纯白；下拉菜单用 `.78/.82` 稍实一档保证小字可读。

## 2. 设计参数（`styles/citro-glass.css` 顶部令牌）

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--g-fill`（默认/Bento/手机） | `linear-gradient(157deg, rgba(255,253,247,.26), rgba(250,244,233,.11) 52%, rgba(244,236,222,.18))` | `rgba(255,246,228,.11→.045→.07)` | 玻璃主填充 |
| `--g-fill`（桌面手账/Bento ≥1025） | `rgba(255,253,247,.10→.02→.05)` | `rgba(255,246,228,.04→.012→.025)` | 桌面玻璃（**只有手机约 1/3，明显更透**） |
| `--g-sheen` | 左上乳白受光 + 118° 斜向高光（白 .14–.16） | 暖白受光（.10–.16） | 玻璃反光 |
| `--g-blur` | 桌面 `blur(1.2px) saturate(1.55)`；手机 `blur(5px) saturate(1.5)` | 同档，saturate 1.3 | **故意低模糊**，让网格可见 |
| `--g-line` | `transparent`（无白边） | `transparent` | 描边 |
| `--g-hi` | 桌面 `inset 0 1px 0 rgba(255,255,255,.28)`；手机 `.50` + 底部暗内影 | 暖白内高光 `.10` | 玻璃厚度 |
| `--g-shadow` | 暖色低对比长投影 | 黑色长投影 | 离面感 |

| `--g-pop-bg` / `--glass-pop-bg` | `rgba(252,248,241,.68)` + `blur(26px)` | `rgba(24,24,28,.72)` + 26px | 弹窗玻璃底 |
| `--g-pop-bg-strong` | `.78` + 24px | `.82` + 24px | 下拉菜单 / 通知面板（小字更密） |
| `--g-pop-sheen` | 左上乳白受光（白 .55） | 暖白受光 `.10` | 弹窗受光 |
| `--g-pop-line` | `rgba(190,122,48,.16)`（暖色，不是白边） | `rgba(255,203,142,.14)` | 弹窗边 |
| `--g-pop-tint` | 右上暖橙 `.18` + 左下鼠尾草 `.12` | 暖橙 `.10` + 鼠尾草 `.06` | 弹窗主题色晕染 |
| `--g-me-blur` / `--g-me-mobile-blur` | 24px / 16px | 同档 | 「我的」页面板玻璃 |

> 电脑端一度比手机端「实」：手账层原为 5–7px 模糊里取 7px、底 15%–30%，另有品牌色叠加（最高 46%），
> Bento 内层小卡还有 20% 白色平涂，且纸面还有 55% 白色受光罩把网格冲淡。现已把桌面统一到 4px / 3%–14%，
> 品牌色叠加减到 4%–11%，内层小卡平涂降到 4%（深色 2%），纸面白受光降到 16%；并在桌面左栏（天气/日历/星象/社区区）直接加大块橙/绿水彩；最终桌面 fill 再压到 `.10/.02/.05`、模糊 `1.2px` —— 桌面卡内方格与水彩能直接看见，比手机更透。

网格：手账纸页 32px 方格线 `rgba(110,88,58,.24)/.15`；全局画布（Bento / 手机）方格 `rgba(110,88,58,.16)/.10`；
深色对应 `rgba(255,220,170,.08)/.055`——都比升级前加深一档，保证透过玻璃仍可读。

同时覆盖了 `citro-core.css` / `citro-refine.css` 的 `--glass-card-bg`、`--card`、`--glass-bg`、
`--glass-pop-*` 等 token（浅/深两套），让所有走 token 的页面自动跟上，不用逐页复制材质。

## 3. 玻璃作用面

- **首页 · 桌面手账（≥1025×880）**：天气 / 日历小组件、摸鱼卡、星象卡、社区 / 食谱海报、每日一言、
  12 张小游戏拍立得、Mod 照片卡、顶部账号/主题/导航胶囊。
- **首页 · Bento（≤1024 宽或 <880 高）**：所有顶层 `.tile`（Hero/Mod/工具/驱动/入口卡/底栏），
  内层 `.mod-card/.gcard/.tool-card` 只做半透平涂；底栏搜索与一言的玻璃由 `::before` 承载。
- **手机 App 壳（≤1024）**：首页天气/日历/摸鱼/星象/食谱卡、底部 Tab 栏；模糊 5px（≤640 仍 5px）。
- **内容页**：社区（门禁卡、个人卡、时钟、菜单、收件箱、发帖框、动态卡、右侧天气/日历卡、朋友圈卡）、
  食谱（侧栏、顶栏、食谱卡、详情、计时器、找菜/冰箱条目、弹层）、我的（桌面路由面板、桌面头像弹窗、手机整页三种形态均玻璃化；面板内账号卡/菜单行亦为玻璃）、
  抽奖记录、灵敏度面板、搜索页头、游戏页侧栏与排行榜卡、My 桌面居中面板。
- **浮层**：登录/注册、资料、赞赏码、番茄钟、运势/星盘、天气弹层、搜索建议面板等统一 `--glass-pop-*`。

## 4. 必须遵守的约束（踩过的坑）

1. **不能在含 `position:fixed` 后代的元素上直接加 `backdrop-filter`**：会造出新的包含块，
   把固定定位弹层困在卡片里。已确认的雷区：
   - `.tile-meta`：≤1024px 时内部 `.fish-pop` / `.wx-pop` 是 fixed（实测给 `.fish-wrap` 直接加 blur 后
     `.fish-pop` 的 y 坐标变成 -195、直接飞出屏幕）。所以：
     - `.tile-meta` 只在「宽 ≥1025 且矮于手账阈值」的桌面 Bento 下直接上玻璃；
     - 手机首页 `.fish-wrap` 只做「无 blur 的半透玻璃」（半透底 + 顶光），保定位正确；
   - `.tile-foot-search` / `.tile-foot`：内部 `.fs-panel` 是 fixed，本体已强制
     `backdrop-filter:none!important`，玻璃由无后代的 `::before` 承载（手账桌面的每日一言例外，
     那一张改用本体直接玻璃且其内部没有 fixed 弹层）。
2. **模糊半径必须小于网格间距的 1/4 左右**：24px 模糊会把 32px 间距的 1px 网格线抹平，
   导致「透了但什么都没透出来」。当前桌面 4px、手机/Bento 5px（同样远小于 32px 网格间距）。
3. **不要 blur 叠 blur**：外层卡是玻璃时，内层小卡只做半透平涂（`.mod-card/.gcard/.tool-card/.cc-vis` 等）。
4. **不加白边**：`--g-line`/`--glass-line`/`--glass-pop-line` 均不用白色；需要边缘感时只加深投影与内高光。
5. **深色不加彩色大面积光晕**：只加 5%–14% 的暖橙 / 鼠尾草微光，保持纯平近黑基调。
6. 发帖框等长文本区用更实的 `--g-filled`；手机全屏发帖编辑器保持不透明（沿用旧结论）。

## 5. 顺手修掉的旧 bug

- **手机深色残留浅色卡**：`citro-scrapbook.css` 多处写成 `html[data-theme="dark"] html.app-shell …`
  （双 `html` 永不匹配），导致 390×844 深色下日历卡、天气格子、星象环仍是浅色。
  玻璃层用 `html.app-shell[data-theme="dark"] …` 能命中的选择器补齐（同时给日历补了深色文字）。
- **`.tile-foot-search` / `.tile-foot` 本体残留 blur**：core `.tile` 的 blur 会盖掉早先的内联 `none`，
  现在由玻璃层强制 `none!important`，避免固定定位弹层的包含块问题。

## 6. 降级与无障碍

- `@supports not ((backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px)))`：
  自动把玻璃令牌换成不透明奶油纸 / 炭黑纸，保留描边与投影。
- `@media (prefers-reduced-transparency: reduce)`：同上回退。
- `@media (prefers-reduced-motion: reduce)`：保留材质，关掉悬停过渡。
- 文字颜色未改动；玻璃底色仍在奶油/炭黑一侧，正文与次要文字对比度保持。

## 8. 打包提醒

仓库里若存在 APK / 离线包副本（例如 `kotlin/app/src/main/assets/www/`，此前还有 `capacitor/www/`），
本轮只改根目录的 `index.html` 与新增 `styles/citro-glass.css`；打 APK / 离线包前需要：
1. 把 `styles/citro-glass.css` 同步进对应 www 的 `styles/`；
2. 确认 `index.html` 里新增的那行 `<link rel="stylesheet" href="styles/citro-glass.css">` 已随 `index.html` 一起同步；
3. 沿用现有同步流程（如 `kotlin/sync-www.js` / `capacitor/sync-www.js`，以仓库当前实际存在的脚本为准），
   否则原生端仍是旧视觉。
