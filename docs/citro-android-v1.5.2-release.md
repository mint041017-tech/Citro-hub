## 本次改动

1. **我的页通知**：通知提醒移到外观之前，并加开关。开关关闭时停止社区通知和烹饪计时系统提醒，清空已排程通知；重新开启会检查/申请系统通知权限。
2. **食材数量与单位换位**：食谱编辑器中数量输入框在左、单位选择在右，免数量单位仍显示提示。
3. **步骤配图改为小方图**：编辑器里的步骤图改为 84×84 方框预览，详情页改为 88×88 方框预览，均保留红色移除按钮/圆角。
4. **详情页自定义计时器**：步骤标题右侧加入「自定义计时」，可选 1–180 分钟并启动，沿用顶部计时条与到点提醒。
5. **详情字体放大**：步骤正文与小记正文从 12.5 提升到 14.5，行高同步调整。
6. **下厨日记只读**：详情页移除「＋ 记一笔」，保留日记展示；空状态改为「还没有下厨记录」。
7. **食谱卡片方图**：卡片封面改为 1:1，网格高度按卡片宽度动态计算，两列布局不再留大片空白。
