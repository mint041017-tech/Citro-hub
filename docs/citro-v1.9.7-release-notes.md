# Citro 1.9.7 更新日志

2026-10-29 · 版本 1.9.7（Android versionCode 1907）· Web / Windows / Android / iOS 源码同步

本版把「听隅」白噪音空间正式并入 Citro，并补齐番茄钟、呼吸引导、卡面收藏与每日抽卡、CiCi 图片消息与善举审核。Android、Windows、Web 已完成构建；iOS 源码与 Live Activity 工程就绪，IPA 需在 Mac 上出包。

## 新增

### 听隅 · 白噪音空间

- 首页右上角圆形「听隅」入口；Web 桌面端保留首页时间组件，并继续提供听隅小工具卡。
- 多轨混音、总音量、定时渐弱、收藏声音、本地音频导入。
- 独立顶栏：返回、听隅 logo 与名称、番茄钟、带秒时钟；竖屏 logo 紧贴返回键。
- 横屏不额外加顶栏，返回按钮放在最左；窄屏时钟自动只显示时分秒。
- 时间支持鼠标悬停反馈；整体沿用 Citro 的 Noto / ZCOOL / Kalam 字体体系。

### 番茄钟

- 顶栏按钮改为「番茄钟」胶囊，开始倒计时后显示 mm:ss，暂停时保留剩余时间，并紧贴时钟组件。
- 到点全局弹窗，同时推送系统通知、播放提示音、震动提醒。
- Android 使用常驻倒计时通知；iOS 接入 ActivityKit 实时活动（Live Activity）。
- 弹层重新设计：刻度进度环、渐变主按钮、今日番茄统计；在听隅内使用绿色同色化配色。
- 暂停、重置或切换模式时，自动清理常驻通知和预约提醒，避免残留。

### 呼吸引导

- 吸气 4 秒 / 呼气 6 秒切换时播放柔和提示音并轻震；引导结束同样有提示。
- 底部引导按钮改为居中紧凑药丸，并使用听隅强调色。

### 卡面收藏与每日抽卡

- 111 张卡面（CiCi / 岁岁 / 月饼），卡背迁移到 OBS 并压缩加载。
- 收藏页支持分类浏览、已收藏 / 未解锁状态、缩放查看。
- 每日打卡展示今日卡面；转运时同步重抽；保留翻面动画、光晕与纸屑效果。
- 抽卡机会：每完成 7 局游戏最多获得 2 次/天；每日首次发图片动态、首次公开菜谱、首次与 CiCi 聊天各获得一次。

### CiCi

- 使用圆形头像；聊天支持发送图片。
- 好事审核更严格：必须能证明真实助人或公益捐赠（含截图），空泛描述、口号或无关图片不通过。

## 优化

### 咕噜果冻

- 新的生成规则：开局仅 2 颗，按阶段逐步解锁更高数值；首次合成到对应层级时立即解锁。
- 禁用长按选中、拖拽文本与浏览器长按菜单。
- 完成深色模式适配。

### 数独

- 填写正确数字后，自动移除同行、同列、同宫中的同数字笔记，并支持撤销。
- 暂停弹层完全遮挡棋盘；退出与继续游玩两个弹窗的按钮均匀铺满，不再挤在中间。

### 深色模式

- 记忆卡牌卡背降低亮度；成语接龙、飞花令、咕噜果冻完成适配。
- 深色下弹窗、按钮、文字和卡片对比度统一调整。

### 手机体验

- 支持左右滑动切换标签页。
- 「我的」页面按平台重新排版与美化。
- 修复 CiCi 聊天输入框文字错位。

## 修复

- 听隅横屏返回按钮位置、窄屏顶栏拥挤。
- 数独两个确认弹窗按钮分布不合理。
- 深色模式下记忆卡牌卡背过亮。
- CiCi 输入文字错位。
