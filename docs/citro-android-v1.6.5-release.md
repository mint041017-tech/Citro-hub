## 极限刹车：道路 / 护栏 / 路障专项

针对「要有清晰明了的道路、两侧护栏（路灯非必须）、以及很清晰的路障」：

**渲染层修复（关键）**

- 定位到此前「道路/标线/护栏整片不画」的根因：`_quad` 的近平面裁剪在远距离
  薄面片上会退化成空多边形被整片丢弃。主结构（道路、边线、护栏、路障）改用
  新的**直投面片 `_face()`**（任一点在相机后方才整片跳过），并给车道线设了
  世界宽度下限，避免亚像素宽度被丢弃。
- **路面**改为「整块多边形 + 纵向渐变」：左右边缘按近密远疏采样 26 个点连成
  一条长条，一次填充（近处 #4E3E34 → 中段 #6B5546 → 远段混雾暖色），不再出现
  分段色块与接缝；左右路缘石各一条同款长条。
- **标线**：白色边线（±5.4）、黄色边线（±6.6）改为整条多边形；车道虚线
  （±1.8，6m 划 6m 空）宽度提升到 0.5m 保证可见。
- **护栏**：从 `_quad` 逐段改为**两条整条多边形带**（±7.35，y 0.55→1.15）+
  受光顶沿高光 + 200m 内每 4m 的立柱，颜色提亮到 #D5DAE2（混雾）。
- **路障**：去掉 1600m 可见上限 —— 近距离照常画 7 个橙白水马 + 9×2.2 红色
  警示板；远距离再叠一条**保底 30px 宽的橙红高亮带 + 顶部白条 + 呼吸警示灯**，
  做到起步 2500m 外就能一眼看到路障在逼近。
- 路面整体提亮一档（原实现近路面几乎与草地同色，视觉上「没有路」）。
