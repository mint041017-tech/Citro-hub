## ⚠️ 服务端需要同步更新

账号注销与举报依赖新的后端接口：

- `POST /api/auth/delete`：密码确认后永久删除账号与个人数据
- `POST /api/report`：写入举报队列 `trash/data/reports.json`

**只安装新 APK 而服务器仍是旧版 `trash.js` 时，注销/举报会返回 404。**
上线顺序：备份 `trash/data` → 替换 `trash/trash.js` → 重启服务 → 再发 APK。
按现有约定，本轮未部署服务器，也未改动线上数据。

## 1. 账号注销（App 内）

- 入口：「我的 → 账号 → 注销账号（永久删除）」。
- 二次确认：勾选「不可恢复」+ 输入登录密码；服务端再次校验密码，错误密码不会删除任何数据。
- 注销范围：
  - 账号、会话、头像、生日 / 星座绑定、通知已读记录；
  - 本人帖子、评论、图片、语音，以及在他人帖子下的点赞 / 抱一抱；
  - 笔记、食谱、下厨日记、冰箱、购物清单及食谱图片；
  - 游戏成绩、排行榜记录、在线状态、灯谜成绩；
  - 本机登录态、星座缓存、打卡记录、游戏最高分、抽签记录、摸鱼配置与本机 AI 运势缓存。
- 举报记录：本人提交的举报删除；针对本人内容的举报保留但匿名化（仅用于安全审核）。
- 服务端实现：`trash/trash.js` 的 `/api/auth/delete`；已用隔离数据目录做完整集成测试（注册 → 发帖/评论/点赞/笔记/成绩/举报 → 错密码拒绝 → 正确注销 → 验证残留为 0）。

- AI 对话输入框上方新增提示：AI 生成内容仅供参考；对话会发送至第三方 AI 服务处理，请勿发送敏感信息。
- 隐私政策与用户协议同步说明 GLM 第三方处理与 AI 内容免责声明。

## 4. 社区举报与拉黑

- 每条非本人动态右上角新增「…」菜单；非本人评论长按弹出举报/拉黑菜单。
- 举报原因：垃圾广告 / 辱骂攻击 / 色情低俗 / 违法违规 / 侵犯隐私 / 其他，可选补充说明。
- 后端 `POST /api/report`：
  - 校验目标存在、不能举报自己、10 分钟内重复举报去重；
  - 保存被举报内容短快照、targetUid、举报人、时间与状态到 `trash/data/reports.json`；
  - 与账号注销联动清理/匿名化。
- 拉黑为**本机黑名单**：在动态/评论菜单中拉黑后，该昵称的动态、评论、收件箱消息与「TA 的发布」立即隐藏；「我的 → 隐私与协议 → 黑名单」可解除。匿名昵称每次随机，匿名内容建议直接举报。
- 社区底部提示改为「可举报或拉黑」。
