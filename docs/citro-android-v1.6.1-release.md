## 1. 极限刹车：场景可读性专项 + 结算居中

用户反馈「车有了，道路/景观/路障呢」。逐项排查（彩虹条带 + 分段禁用二分定位）：

- **真凶 1：追逐相机太低太近** —— web 桌面参数（camY 2.2 / dist 8.2）在 470 高的
  竖屏 stage 里车尾占近半画面。相机拉高拉远（camY 3.0 / dist 10.8 / brake 态
  同步调整），车缩到约 1/3 宽，路面充分露出。
- **真凶 2：30m 加密路灯的光晕在 45° 视锥下连成蝴蝶状橙雾**，把整条路面染成
  一片。改为：灯距回 45m、灯头光晕半径上限 15px 且只在 130m 内画、远处只留
  小亮点；路面光池限 120m 内且宽度上限 60px。
- **真凶 3：地平线暖光 alpha .92 的全屏径向 + 夕阳反光带**把远景糊死。暖光
  中心 alpha 降到 .66，反光带降到 .18 并放宽，标线不再被冲掉。
- **景观补充**：草地压暗偏绿（#4E4B3C）拉开与路面的层次；新增路肩两侧树剪影
  （每 ~55-70m 一棵、椭圆双层树冠、hash 抖动位置、远景雾化）；护栏梁加高
  （0.42-1.00m）远处可见连续白线。
- **路障全程可见**：去掉 2600m 水马 1600m 的绘制距离上限 —— 起步时地平线上
  就有红橙色路障剪影随接近变大。
- **结算卡居中**：`Positioned.fill + Center` 水平垂直双居中（原来是 web 的
  贴顶定位）。

## 2. 贪吃蛇 / 数字华容道结算卡统一为淘气小球样式

两游戏的结算浮层改成与淘气小球同一套：半透明纸面 `FCF8F0@94%` + 边框
`2E2C22@16%` + 圆角 22 + Kalam 22px 标题 + 13px 灰描述（数字金棕 #8A5A12
加粗高亮）+ 主按钮「再来一局」垂直居中。文案保留各自内容。

## 3. 成语接龙 / 飞花令 键盘体验

- **键盘弹出时隐藏「正在玩」条**（GameScaffold 读 viewInsets，两种布局都生效）。
- **提交后不收起键盘**：onSubmitted 提交后立即 `focusNode.requestFocus()`，
  IME 的「完成」不再把键盘收走，可连续作答。
- **错误提示浮层化**：错误 / AI 判定提示从底部输入区改为挂在链表区顶部的
  居中胶囊浮层（纸面+描边+投影，不占布局），始终在屏幕上方。
- **关键信息常驻键盘上方**：接龙在输入行上方加「需接 x」描边徽章、飞花令加
  「令字 花」徽章 —— 键盘弹出遮住顶部拼音/令字大字时，输入框旁仍可见。
