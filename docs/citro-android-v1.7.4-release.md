## 极限刹车：成绩自动上榜

历史上成绩一直进不了榜单，根因是桥接层参数传错：

```js
// 错误：数组会被 flutter_inappwebview 当成「一个 List 参数」
bridge.callHandler('citroScore', [body])
```

原生回调里 `args.first` 因此不是 Map，`_onScore` 永远判成空成绩。
v1.7.4 改为按可变参数摊平：

```js
b.callHandler.apply(b, [name].concat(args))
```

同时原版结算面板的昵称输入 + 提交按钮在 Citro 版里早已移除，成绩没有
任何提交入口。现在由桥接层监听结算面板：

- 成功刹停 → 等待 0.9s 得分滚动结束 → 自动提交 `citroScore`
- 结算页显示「已上榜 · 当前第 N 名 / 成绩已上榜 · 最高 N 分」
- 失败/翻车不提交
- 同一局去重，重复点按不会重复提交
- 原生 handler 返回 `ok / best / rank`

## 顶栏与入口

- 补上与其他小游戏一致的顶栏：返回圆钮放大到 42、品牌「游戏空间」严格居中、右侧账号钮。
- 排行榜不再占用顶栏：开始页「开始挑战」下方、结算页「再来一次」下方
